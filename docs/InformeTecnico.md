# Informe Técnico
## Registro de Animales Perdidos

### 1. Nombre del proyecto

Registro de Animales Perdidos

### 2. Descripción del proyecto

El proyecto consiste en desarrollar un sistema que permita registrar y consultar información sobre animales perdidos.

La idea principal es facilitar el registro de los animales que se encuentran perdidos, almacenando información importante como su nombre, especie, características, lugar donde se perdió y datos de contacto de la persona responsable.

El sistema permitirá organizar esta información para facilitar la búsqueda y ayudar a encontrar a los animales perdidos.

### 3. Problemática

Actualmente, cuando una mascota se pierde, muchas veces la información se publica en diferentes lugares y puede ser difícil encontrarla o mantenerla organizada.

Por esta razón, se propone crear un sistema que permita registrar los datos de los animales perdidos de manera ordenada y facilitar posteriormente su consulta.

### 4. Objetivo general

Desarrollar un sistema para registrar, consultar, modificar y eliminar información relacionada con animales perdidos.

### 5. Objetivos específicos

- Registrar los datos de los animales perdidos.
- Consultar los animales registrados.
- Modificar la información de un registro cuando sea necesario.
- Eliminar registros que ya no sean necesarios.
- Mantener la información organizada en una base de datos.
- Facilitar la búsqueda de información sobre animales perdidos.

### 6. Usuarios del sistema

El sistema estará dirigido principalmente a personas que necesiten registrar o consultar información sobre animales perdidos.

### 7. Funcionalidades principales

El sistema contará con las siguientes funcionalidades:

- Registrar un animal perdido.
- Consultar animales registrados.
- Actualizar información de un animal.
- Eliminar un registro.
- Buscar información de animales registrados.
- Almacenar los datos en una base de datos.

### 8. Información que se registrará

Para cada animal se podrá almacenar información como:

- Identificador del animal.
- Nombre.
- Especie.
- Raza.
- Color.
- Descripción.
- Fecha en que se perdió.
- Lugar donde se perdió.
- Datos de contacto del responsable.
- Estado del registro.

### 9. Tecnologías

Para el desarrollo del proyecto se utilizarán herramientas y tecnologías como:

- Visual Studio Code.
- C#.
- Windows Forms.
- SQL Server.
- Git.
- GitHub.

### 10. Arquitectura del sistema

El proyecto estará organizado utilizando una estructura por capas, con el objetivo de separar las diferentes responsabilidades del sistema.

Las principales capas serán:

- Entidades: representa los datos que utilizará el sistema.
- DAL: se encargará del acceso a la base de datos.
- BLL: contendrá la lógica y reglas del sistema.
- UI: corresponderá a la interfaz que utilizará el usuario.

### 11. Base de datos

La información del sistema será almacenada en una base de datos de SQL Server.
