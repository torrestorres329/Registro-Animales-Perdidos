# Registro de Animales Perdidos

## Descripción

Proyecto académico para desarrollar un sistema de registro y gestión de animales perdidos.

## Objetivo

Permitir registrar, consultar, actualizar y eliminar información de animales perdidos.

## Tecnologías

- C#
- .NET
- Windows Forms
- SQL Server
- GitHub

## Estructura del proyecto

- docs: Documentación y diagramas.
- database: Scripts de base de datos.
- src: Código fuente de la aplicación
