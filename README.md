# Registro de Animales Perdidos

## Descripción

Proyecto académico para desarrollar un sistema de registro y gestión de animales perdidos.

## Objetivo

Permitir registrar, consultar, actualizar y eliminar información relacionada con animales perdidos.

## Tecnologías

- C#
- .NET
- Windows Forms
- SQL Server
- GitHub

## Estructura del proyecto

- `docs`: documentación y diagramas del proyecto.
- `database`: scripts y procedimientos almacenados de la base de datos.
- `src`: código fuente de la aplicación.
